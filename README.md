# astroglial-morphology

## About

`astroglial-morphology` is a Python toolkit for analysing astroglial morphology
in microscopy data. It performs Suite2p-based registration, generates image
projections, segments cells with Cellpose, and supports interactive mask
correction through a Streamlit GUI. The pipeline can also export morphology,
correspondence, and fluorescence-trace data for downstream analysis.
